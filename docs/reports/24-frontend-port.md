- 검증한 커밋: `ef15fa3`(문서 `6ef4730`)

## 목표

`make dev` 로 띄운 화면이 다른 프로젝트의 개발 서버와 포트가 겹치지 않는다.

## 고른 포트

- 다른 프로젝트들의 설정 파일(package.json · nuxt/vite 설정 · .env · compose · 백엔드 소스)과 지금 열린 포트를 모아 봤다.
- 설정에 적힌 포트: 3000(likey-web · vlum-web) · 3001(likey-web https) · 3002 · 3005–3007 · 3009 · 3010 · 3012 · 3100 · 3101(likey-web-4) · 5050 · 5100 · 6379 · 8264.
- 열려 있는 포트: 5000 · 7000 · 6768 · 8765 등.
- 겹치는 것은 프런트의 3000 뿐이다. 그래서 프런트를 둘 다에 없는 **4747** 로 옮겼다.
- 백엔드 **8000** 은 어느 설정에도 없고 비어 있어 그대로 둔다. 훅 기본 주소(`localhost:8000`)가 바뀌지 않으니 설치해 둔 훅도 그대로 쓴다.

## 한 일

- `frontend/package.json` 의 `dev` 를 `next dev --turbo --port 4747` 로.
- 백엔드 기본 CORS · 웹소켓 허용 출처를 `localhost` · `127.0.0.1` · `0.0.0.0` 의 4747 로. 백엔드가 시작할 때 찍는 토큰 링크도 4747 로.
- 문서: README · 빠른 시작 · 프런트 README · 스크립트 README · CONTRIBUTING · CLAUDE.md · OpenCode 설치 안내의 주소를 4747 로. 지난 보고서 · 감사 문서는 그때 기록이라 두었다.

# 12 · 화면 재설계 계획

- 브랜치: `docs/12-iso-redesign-plan`
- 근거: 사용자 지시(2026-10-20) — "내가 처음에 준 스레드 링크의 스크린샷과 똑같은 디자인으로 만들어."

## 목표

지금 화면(원본의 2D 픽셀 사무실)을 게시물 영상과 같은 화면으로 바꾸는 계획을 세운다.

## 한 일

- 게시물 영상(88초 · 1280×618)과 작성자 댓글을 헤드리스 브라우저로 받아 확인했다. 처음에는 로그인 없이 볼 수 없다고 판단해 본문 문장만 근거로 삼았었다.
- [근거 문서](../plan/spec.md)에 「화면 재설계」 절을 더했다.
  - 화면 구성: 가운데 등각 사무실 한 층, 왼쪽 층별 안내, 오른쪽 사람들 · 활동 로그 · 방 범례, 캐릭터와 말풍선 모양
  - 방 ↔ 도구: 방 일곱 곳과 활동 여섯 가지. `WebFetch` · `WebSearch` 는 작성자 댓글대로 자료실에서 정보검색실로 옮긴다
  - 구현 방침: three.js 직교 카메라 장면 + HTML 말풍선, 다 갖출 때까지 지금 화면을 기본으로 두기, 영상 캡처는 저장소에 넣지 않기
- [작업 분할](../plan/work-breakdown.md)에 13–20 을 넣었다. 10(Codex)은 재설계 뒤로 미뤘다. 그 브랜치에는 「읽기만 하는 셸 명령은 자료실」 커밋까지 올라가 있다.

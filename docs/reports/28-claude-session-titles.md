# 28 · Claude Code 가 붙인 세션 제목

- 브랜치: `fix/28-claude-session-titles`
- 근거: 사용자 요청 — 「왜 다 제목 없는 세션으로 나오지?」(층별 안내의 세션 7개 중 6개가 「제목 없는 세션」), [18 보고서](18-floor-guide.md)의 세션 제목
- 검증한 커밋: `5544130`

## 목표

층별 안내 · 머리말의 세션 제목으로 Claude Code 가 붙인 세션 이름을 쓴다.

## 원인

- 세션 제목은 백엔드가 받은 첫 질문(`UserPromptSubmit`) 이벤트에서 만들었다.
- 훅을 연결하기 전부터 돌던 세션은 첫 질문을 이미 지나쳐서, 그 뒤로 새 질문이 없으면 제목을 만들 거리가 없다.
- 새 세션도 첫 질문이 `/clear` · `/effort` 같은 명령인 일이 많아 제목으로 쓸 수 없다.

## 한 일

- Claude Code 는 세션 이름을 기록 파일(transcript)에 `{"type": "ai-title", "aiTitle": …}` 줄로 남기고, 대화가 이어지는 동안 파일 끝 근처에 다시 쓴다. 실제 기록 파일 6개에서 최신 줄은 끝에서 30KB 안에 있었다.
- 세션 목록은 훅 이벤트가 알려 준 기록 파일의 끝 256KB 에서 최신 `ai-title` 을 읽어 제목으로 쓴다. 없으면 지금처럼 첫 질문을 쓴다.
- 기록 파일은 수 MB 라 크기가 그대로면 다시 읽지 않는다. 읽기는 이벤트 루프 밖에서 한다. `~/.claude` 아래 `.jsonl` 만 읽는다(기존 경로 검사).

## 검증하지 못한 것

- 화면 캡처 — 이 저장소는 공개라 실제 업무 세션 이름이 담긴 화면을 싣지 않는다. 가짜 기록 파일로 찍던 화면 확인은 사용자가 중단해 하지 않았다. 화면은 이미 있던 제목 표시를 그대로 쓰고(바뀐 것은 API 의 제목 값뿐), 머지 뒤 사용자 화면에서 확인한다.
